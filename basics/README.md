# Shell, basics

- 0-current_working_directory: prints the current working directory
- 1-listit: lists the current directory
- 2-bring_me_home: goes to the home directory
- 3-listfiles: lists in long format
- 4-listmorefiles: lists in long format with hidden files
- 5-listfilesdigitonly: like 4 with numeric user and group IDs
- 6-firstdirectory: creates /tmp/my_first_directory
- 7-movethatfile: moves /tmp/betty into /tmp/my_first_directory
- 8-firstdelete: deletes betty
- 9-firstdirdeletion: deletes /tmp/my_first_directory
- 10-back: goes to the previous directory
- 11-lists: lists current, parent and /boot directories
- 12-file_type: prints the type of /tmp/iamafile
- 13-symbolic_link: creates a symbolic link __ls__ to /bin/ls
- 14-copy_html: copies new or updated HTML files to the parent directory
- 15-lets_move: moves files starting with an uppercase letter to /tmp/u
- 16-clean_emacs: deletes files ending with ~
- 17-tree: creates welcome/to/school

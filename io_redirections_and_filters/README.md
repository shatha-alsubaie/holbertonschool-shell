# Shell, I/O Redirections and filters

Each script uses redirections, pipes and filters:
- 0-hello_world: prints Hello, World
- 1-confused_smiley: prints a confused smiley
- 2-hellofile: displays /etc/passwd
- 3-twofiles: displays /etc/passwd and /etc/hosts
- 4-lastlines: last 10 lines of /etc/passwd
- 5-firstlines: first 10 lines of /etc/passwd
- 6-third_line: third line of iacta
- 7-file: creates a file with a special name
- 8-cwd_state: writes ls -la into ls_cwd_content
- 9-duplicate_last_line: duplicates the last line of iacta
- 10-no_more_js: deletes all .js files recursively
- 11-directories: counts subdirectories
- 12-newest_files: 10 newest files
- 13-unique: words appearing exactly once
- 14-findthatword: lines containing root
- 15-countthatword: number of lines containing bin
- 16-whatsnext: lines with root and 3 lines after
- 17-hidethisword: lines without bin
- 18-letteronly: lines starting with a letter
- 19-AZ: replaces A with Z and c with e
- 20-hiago: removes c and C
- 21-reverse: reverses input
- 22-users_and_homes: users and their home directories sorted
